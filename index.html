How overclocking works

Prestige a tool in /tree (every 100 levels). You get 2 divine keys, plus a 50% chance that one random enchant on the tool levels up. An overclockable enchant that is already maxed goes one level past its max. Swords can only hold one overclocked damage enchant at a time.

Read from the SkyBlock source code on GitHub. Numbers are what the code says, so the live server may differ. Proc chances are per hit or block break.
